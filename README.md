# ことばのたね｜英単語

中学生向けの静的な英単語学習アプリです。HTML・CSS・JavaScriptだけで動き、ビルド作業は不要です。

## GitHub Pagesで公開する

1. GitHub の `english` リポジトリを開きます。
2. `outputs`フォルダの中身をリポジトリのルートへアップロードします。`index.html`、`app.js`、`styles.css`、`data/words.json`、`data/SOURCES.md`、ライセンスファイル、`assets/angel-stamp.png`の配置を保ってください。
3. **Settings → Pages** で `main` ブランチの `/ (root)` を公開元に選びます。
4. 公開URLをスマートフォンで開きます。ホーム画面への追加もできます。

## 単語データ

`data/words.json`には5,000件の異なる見出し語があります。元の40件はIDと内容を維持し、追加分は4,764件をLexiCore-5000の語彙候補とEJDict-handの訳語から編集し、196件をEJDict-handの頻度リストから補っています。重複見出しとIDを検査済みです。各データには出典ラベルと頻度順位（利用可能な場合）があります。

この5,000語は学習範囲を広げるための参考語彙で、文部科学省や特定教科書の公式な配当表を完全収録したものではありません。LexiCoreの頻度帯1～5は各1,000位ごとの順位帯であり、学年を示しません。MEXTの解説は小学校600～700語程度、中学校で新語1,600～1,800語程度を加える語数の目安を示していますが、固定の公式単語一覧ではありません。

例文は元の40件のみ収録し、追加4,960件は空欄のままです。出典にない例文を捏造せず、クイズでは「例文は未収録です」と表示します。日本語訳は辞書記載の先頭寄りの意味を短く整形したものが中心で、文脈によって訳が変わる語や語義・品詞の確認が必要な場合があります。LexiCoreのREADMEにも品詞・レベル推定の限界が記されています。学校の授業や教科書の範囲と照らして使ってください。

詳しい出典、加工内容、重複確認、ライセンスは [`data/SOURCES.md`](data/SOURCES.md)を参照してください。文部科学省資料は[公式PDF](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_010.pdf)です。

## 保存

学習履歴はブラウザの`localStorage`に保存されます。同じ端末・ブラウザ間でのみ使え、スマートフォンとPCの自動同期はありません。設定画面からJSONを書き出し、定期的にバックアップしてください。復元は現在の記録を置き換えます。
