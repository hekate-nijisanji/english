# ことばのたね｜英単語

中学生向けの、毎日5語を目安に学ぶ静的Webアプリです。HTML・CSS・JavaScriptだけで動き、ビルド作業は不要です。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作ります。
2. `outputs`フォルダの中身（`index.html`、`styles.css`、`app.js`、`data/words.json`）をリポジトリのルートへアップロードします。
3. リポジトリの **Settings → Pages** を開き、公開元に `Deploy from a branch`、ブランチに `main` と `/ (root)` を選んで保存します。
4. 表示されたURLをスマートフォンで開きます。ホーム画面に追加するとアプリのように使えます。

`index.html`をファイルとして直接開くと、ブラウザの制限で単語JSONを読み込めないことがあります。GitHub Pages上で開く方法が一番簡単です。

## 今ある機能

- 新出語を最大5語ずつ割り当て、進捗と途中再開を保存
- 英語→日本語／日本語→英語の4択
- 正誤履歴、復習間隔、苦手語の再練習
- 月間カレンダー、日別記録、学習日数・連続日数
- 学習段階・品詞・新出/復習別の成績
- JSONバックアップと復元
- 学習記録をブラウザ内に保存（端末間の自動同期なし）

## 単語データについて

`data/words.json`が独立した単語データです。現在40語を収録しています。小学校・中学校の学習範囲を意識した編集者作成の例で、文科省の公式語彙一覧や教科書の完全な配当語リストではありません。文科省の学習指導要領解説は小学校600～700語程度、中学校で新語1,600～1,800語程度を加える語数の目安を示しますが、固定された網羅語彙一覧を定めているわけではありません。

5,000語目標まであと4,960語です。無断転載を避けるため、初期データは独自に編集した単語・短い例文で構成しています。語を追加する際は、語彙・訳・例文の確認と、元データの利用許諾を確認してください。`id`は重複させず、各項目に`word`、`meanings`、`pos`、`stage`、`example`、`exampleJa`を設定します。不規則変化は任意の`forms`（`past`、`pastParticiple`、`ing`）へ追加できます。学習段階は「小学校」「中1」「中2」「中3」などで登録します。

参考：文部科学省『中学校学習指導要領（平成29年告示）解説 外国語編』[公式PDF](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_010.pdf)。語数目標の参考であり、このJSONに同文書から単語リストを転載したものではありません。

## 保存と復元

記録はブラウザの`localStorage`に保存されます。同じブラウザ・端末の範囲で使い、ブラウザのサイトデータを削除すると記録が消える場合があります。定期的に設定画面からJSONを書き出してください。復元時は現在の記録を置き換えるため、必要なら先にバックアップします。

## データ不足と次の拡張

この初期版は40語であり、約5,000語の完成データではありません。追加データを得るときは、まず信頼できる公開リストの配布条件を調べ、再配布・加工の条件、元出典、版、確認日を記録してください。学校ごとに教科書の語彙配当が異なるため、「中学必修語」と断定しないラベル付けが必要です。新しい語は出典・訳・例文を確認した上でJSONへ追加してください。
